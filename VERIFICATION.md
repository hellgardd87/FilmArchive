# Результаты проверки

Дата: 7 октября 2026 года.

## Выполнено

- Все 35 основных Java-классов и два набора unit-тестов скомпилированы через javac --release 21.
- 13 unit-тестов выполнены: 13 успешно, 0 ошибок.
- Проверены соответствие th:field свойствам DTO, наличие маршрутов и фрагментов, корректность структуры HTML и обязательных Maven-зависимостей (tools/check_contracts.py).
- JavaScript проверен через node --check.
- Проверены названия свойств Film, DTO, Repository, Service и шаблонов, связь film_people и отсутствие каскадного удаления.

## Ограничения среды

Maven-сборка была запущена, но не смогла загрузить spring-boot-starter-parent:3.5.16: сетевое соединение с Maven Central запрещено средой (Permission denied: getsockopt). В PATH отсутствовали Java и Maven; для отдельной компиляции использованы инструменты установленной IntelliJ IDEA.

Для отдельной проверки использован доступный локальный кэш библиотек Spring Framework 7 / Spring Boot 4 / Hibernate Validator 9, компиляция в байткод Java 21 и запуск на JDK 25. Тесты запускались отражением аннотированных JUnit-методов, а не Maven Surefire. Это проверяет исходный Java-код и бизнес-проверки, но **не заменяет сборку и запуск на зависимостях из pom.xml и JDK 21**.

Локальный PostgreSQL обнаружен, однако соединение с паролем password из примера не прошло аутентификацию. Пользовательская база cinema_db в этой среде не создавалась. Файл database/create-database.sql и compose.yaml предоставляют два способа её создания.

Полный запуск Spring Boot, рендеринг Thymeleaf в работающем приложении, визуальная проверка в браузере и CatalogIT с PostgreSQL не выполнены. Для подтверждения выполните mvn clean verify и mvn -Pintegration verify в среде с сетью, JDK 21 и Docker; затем запустите приложение со своими параметрами PostgreSQL по README.md.
