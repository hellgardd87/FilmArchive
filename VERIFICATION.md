# Результаты проверки FilmArchive

Дата: 8 октября 2026 года.

## Выполнено

- Maven компилирует 54 основных Java-класса и 6 тестовых классов на зависимостях Spring Boot **3.5.13** из текущего pom.xml, с release 21.
- Maven Surefire: **26 тестов, 0 failures, 0 errors**. Сохранены существующие FilmFormTest (7) и FilmServiceTest (6); добавлены PortalServiceTest (6), ExternalServicesTest (4), PortalWebTest (3).
- Реальный Spring MVC / Thymeleaf-рендеринг всех 22 публичных страниц, управления /edit, формы /edit_film/1 и ошибок проверен в MockMvc. Данные каталога в этих тестах подставляются mock-сервисами.
- Каталог проверен с заполненной Film и всеми отношениями; случайный фильм использует существующий FilmService. Проверены результаты калькуляторов, поиска сайта, погоды и валюты, HTTP 400/404/503 и отсутствие внутренних подробностей API-ошибки в HTML.
- HTTP-клиенты валюты и погоды тестируются локальным HttpServer: успешные JSON-ответы, неизвестный город, некорректный ответ и 503.
- python tools/check_contracts.py проходит: маршруты, DTO, сущности, формы, repository, фрагменты и Maven-зависимости согласованы.
- python tools/check_rendered_html.py проходит для **25 готовых HTML-страниц** в target/rendered-html: вложенность, уникальные id, labels, типы кнопок, метаданные, общие header/main/footer и внешние ссылки. Исправлены повторяющиеся id в старых административных формах.
- node --check src/main/resources/static/js/main.js проходит.
- Sitemap проверен XML-парсером; настроенный домен и исключение административных страниц проверены тестом.

## Команда тестирования в этой среде

Java и Maven отсутствуют в PATH; использованы JDK 25.0.2 и Maven из установленной IntelliJ IDEA. Зависимости взяты из локального Maven-кэша, скопированного в .build-cache внутри workspace. Для автономного теста переопределена только версия тестового плагина, поскольку Surefire 3.5.5 не полностью закэширован:

```shell
mvn -o -Dmaven.repo.local=.build-cache -Dmaven-surefire-plugin.version=3.5.6 test
```

Фактический запуск использует Java launcher встроенного Maven; выше показана эквивалентная обычная команда. Версия приложения, Spring Framework, Thymeleaf, JPA и прочие зависимости соответствуют pom.xml. Требуемый Java 21 подтверждён компиляцией release 21; отдельный запуск на JDK 21 в этой среде не выполнялся.

## Ограничения

- Полная упаковка исполняемого Spring Boot JAR не завершилась: в кэше отсутствуют spring-boot-buildpack-platform и spring-boot-loader-tools версии 3.5.13. Попытка скачать их из Maven Central, включая повторный запуск вне sandbox с разрешением, завершилась ошибкой разрешения repo.maven.apache.org. Компиляция и тесты успешно выполняются автономно. Для финальной упаковки нужна среда с доступом к Maven Central и команда mvn clean verify.
- PostgreSQL-интеграционный CatalogIT не запускался: Docker отсутствует в PATH. Его зависимости и профиль integration добавлены в pom.xml; обычные тесты не используют рабочую БД.
- Реальные публичные API не вызывались из Java в этой сети; протоколы сверены с официальной документацией, HTTP-клиенты проверены на локальном API.
- Визуальная проверка в браузере и внешняя проверка W3C Validator не выполнялись. Локальная проверка готового HTML не заменяет W3C. Для неё используйте файлы target/rendered-html либо URL опубликованного сайта.

Прежние отчёты .verification/OfflineTestRunner и классы из предыдущей проверки не используются для подтверждения текущей версии. Актуальные стандартные отчёты — target/surefire-reports.
