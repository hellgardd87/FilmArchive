О проекте

Каталог фильмов

Информационная система для ведения кинотеки.

Все данные о кино в одном месте

Каталог хранит название и описание фильма, дату выхода, длительность, бюджет, кассовые сборы, жанр, страну, возрастное ограничение, качество съёмки и актёрский состав.

Возможности

  • Добавление, редактирование и удаление фильмов.
  • Ведение справочников жанров, стран, возрастных ограничений и качества.
  • Добавление и удаление актёров с корректным обновлением связей.
  • Поиск по жанру и стране с сортировкой по названию.
  • Статистика фильмов, актёров, справочников и связей.

С чего начать

На странице управления заполните справочники и добавьте актёров. Затем создайте фильм, выбрав значения из списков. Для поиска выберите жанр, при необходимости уточните страну и нажмите «Найти».

Удаление фильма сохраняет актёров. Удаление актёра убирает его из всех фильмов, сохраняя сами фильмы. Фильм после удаления его последнего актёра может временно остаться без состава; при следующем сохранении выберите хотя бы одного актёра.
